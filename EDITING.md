# Как редактировать сайт MUST MOVIE MEDIA

Памятка для команды. Программы ставить не нужно: всё делается на github.com в браузере.

Сайт: https://mustmoviemedia.github.io/website/

---

## 1. Доступ

1. Зарегистрируйтесь на github.com (бесплатно) и пришлите свой ник владельцу сайта.
2. Примите приглашение: оно придёт на почту, или откройте https://github.com/mustmoviemedia/website/invitations → **Accept invitation**.
3. Откройте репозиторий: https://github.com/mustmoviemedia/website

Если GitHub пишет «404» или не даёт редактировать — приглашение ещё не принято.

## 2. Как внести правку

1. Откройте нужный файл (список — ниже) и нажмите на значок **карандаша** ✏️ справа вверху.
2. Исправьте текст. Найти строку помогает поиск: **Ctrl+F** (на Mac — Cmd+F).
3. Нажмите зелёную кнопку **Commit changes…**.
4. В окне выберите **Create a new branch for this commit and start a pull request** и коротко напишите, что поменяли. Например: «Новая цена Foto Pro».
5. Нажмите **Propose changes**, затем **Create pull request**.

После этого сайт ещё не меняется. Ваш Pull Request (предложение правки) появится во вкладке **Pull requests**.

- **Автопроверка.** Робот проверит файлы на ошибки. Зелёная галочка ✅ — всё в порядке, красный крестик ❌ — где-то сломана запятая или кавычка.
- **Публикация.** Владелец смотрит правку и нажимает **Merge pull request**. Через 1–2 минуты изменения появляются на сайте.

> Удобнее, если файлов много: на странице репозитория нажмите клавишу **`.`** (точка). Откроется полноценный редактор прямо в браузере.

## 3. Где что лежит

## 4. Как поменять текст

Все тексты лежат в `i18n.js`, три раза: сначала русский (`ru`), потом узбекский (`uz`), потом английский (`en`). У каждой строки свой ключ:

```js
"hero.t1": "Снимаем.",
```

Слева ключ — его **не трогайте**. Справа текст в кавычках — его меняйте.

Как найти нужную строку:
1. Ищите по **Ctrl+F** кусок текста, который видите на сайте. Например, «Снимаем».
2. Запомните ключ (`hero.t1`) и поищите его ещё раз: так вы найдёте ту же строку на узбекском и английском. Исправьте все три языка.

Правила, чтобы ничего не сломать:
- **Кавычки.** Текст стоит в прямых кавычках `"…"`. Внутри текста используйте «ёлочки» или `\"`.
- **Запятые.** Запятая в конце строки обязательна (кроме последней строки в блоке).
- **Разметка.** Не удаляйте `<span>`, `<b>`, `<br>` и ссылки `<a …>` внутри текста, если не уверены.
- **Подстановки.** `{n}`, `{total}` и подобное в фигурных скобках подставляется автоматически — оставляйте как есть.

## 5. Фото и видео

1. Откройте папку `assets/` → **Add file → Upload files** → перетащите файл → дальше как в разделе 2.
2. Чтобы фото появилось на сайте, его нужно прописать в `index.html`. Пришлите разработчику имя файла и место, где оно должно стоять.

Места под материалы помечены на сайте серыми рамками с подписью в квадратных скобках, например «[Превью 4:5 · jpg 1080×1350]». В подписи указан нужный размер.

Рекомендации:
- **Фото:** jpg, не больше 300 КБ. Сжать можно на squoosh.app.
- **Видео:** mp4 (H.264), без звука для фона, не больше 8 МБ.
- **Названия файлов:** латиницей, без пробелов. Например, `case-coffee-1.jpg`.

## 6. Важно

- **Что публикуется.** Всё, что попадает в ветку `main`, сразу уходит на сайт, а изменения в `knowledge.js` и `telegram-worker/` — ещё и в Telegram-бота. Поэтому только через Pull Request.
- **Секреты.** Токен бота, пароли и личные номера телефонов в файлы **не пишем никогда**. Секреты хранятся только в Cloudflare.
- **Если сломалось,** любую правку можно откатить: на странице Pull Request есть кнопка **Revert**, а история всех версий — во вкладке **Commits**.
- **Предпросмотр.** Посмотреть правку до публикации можно на своём компьютере: скачать репозиторий (**Code → Download ZIP**) и открыть `index.html` в браузере. Чат с менеджером локально работать не будет, остальное — да.
