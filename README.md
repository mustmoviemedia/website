# MUST MOVIE MEDIA — сайт-визитка

Статический сайт без сборки: `index.html` + `styles.css` + `site.js`. Общие скрипты: `i18n.js` (переводы), `plans.js` (пакеты и цены), `calc.js` (калькулятор), `brief.js` (бриф), `knowledge.js` + `chat.js` (чат), `script.js` (меню), `analytics.js`. Картинки — в `assets/`. Сервер для чата и брифа — `telegram-worker/`.

## Редактирование командой

Памятка для тех, кто правит тексты, цены и ответы чата без программиста: [EDITING.md](EDITING.md). Каждый Pull Request автоматически проверяется (`scripts/check.js`, запуск вручную: `node scripts/check.js`).

## Что заменить перед запуском

- `assets/logo-white.svg` — сейчас временный логотип, замените на фирменный (то же имя файла).
- `assets/og-image.png` — картинка для превью ссылки в соцсетях (1200×630).
- Все заглушки размечены классом `todo` — найдите их поиском `class="todo` / `todo"` в `index.html`.
- Фоновое видео и шоурил — комментарии `TODO` в `index.html` (размеры указаны там же).

## Языки: RU / UZ / EN

- Все тексты интерфейса — в `i18n.js`, объект `DICT = { ru, uz, en }`. Чтобы поправить перевод, меняйте строку с нужным ключом во всех трёх языках.
- В `index.html` элементы помечены `data-i18n="ключ"` (текст), `data-i18n-html` (текст с разметкой), `data-i18n-placeholder`, `data-i18n-aria-label`, `data-i18n-alt`, `data-i18n-content`. Русский текст в HTML — запасной вариант.
- Цены: `data-money="16.0"` (+ `data-money-per` для «/ мес») — формат подставляется сам: «16,0 млн / мес», «16,0 mln / oy», «16.0 M UZS / mo».
- Пакеты в окне «Подробнее» — `plans.js`, структура `MMM_PLANS[язык][id]`; цены общие, в блоке `META`.
- Язык при первом заходе: `?lang=ru|uz|en` → сохранённый выбор → язык браузера. Ссылка на английскую версию: `index.html?lang=en`.
- Итоговый текст брифа всегда собирается на русском, со строкой «Язык клиента».

## Цены и калькулятор

- Блок «Сколько это стоит» (SC 04): четыре ячейки «от …» считаются сами из минимальных цен в `plans.js`.
- Калькулятор — `calc.js`: мероприятие, Reels / реклама, фото, SMM, прямой эфир, аэросъёмка. Результат — диапазон «≈ от X до Y».
- Цены — `CALC_PRICES` и пакеты в `plans.js`. Верх диапазона (+20%) и наценка за срочность (+20%) — `CALC_RANGE` и `CALC_URGENT`. Список недостающих цен — в начале `calc.js`.
- `CALC_PRESETS` — кнопки «Как Блокбастер», «Как Исторический 1/2/3». Сейчас они дают ровно 170,7 / 97,7 / 57,9 / 27,9 млн.
- Проверка: `node -e "const c=require('./calc.js'); for (const [k,s] of Object.entries(c.presets)) console.log(k, c.compute(s).total)"`.
- Ссылка сразу на нужную услугу: `index.html?svc=reels#calculator` (event, reels, photo, smm, live, aerial).

## Чат и Telegram-бот

- Кнопка «Спросить» справа внизу — `chat.js`. Ответы — из базы знаний `knowledge.js`, общей с Telegram-ботом. Как добавить вопрос без программиста — в начале `knowledge.js`.
- «Позвать менеджера» создаёт тему в группе «ЗАЯВКИ», ответ менеджера приходит клиенту в окно чата. Настройка и шаблоны — `telegram-worker/README.md`.
- Рабочее время — `HOURS` в `knowledge.js` (по Ташкенту).

## Защита от копирования

- `protect.js` и блок «ЗАЩИТА КОНТЕНТА» в конце `styles.css`:
  - текст не выделяется и не копируется; Ctrl+A / Ctrl+C не работают;
  - картинки и видео не сохраняются правой кнопкой, долгим нажатием на телефоне и перетаскиванием;
  - перехвачены Ctrl+S, Ctrl+U, Ctrl+P, F12 и Ctrl+Shift+I;
  - при печати выводится только подпись ©.
- Поля ввода, бриф и чат работают как обычно: там можно выделять, копировать и вставлять. Чтобы разрешить копирование ещё где-то, добавьте элементу атрибут `data-copy-ok`.
- Если длинный текст всё же скопирован, к нему добавляется «© MUST MOVIE MEDIA» и адрес сайта.
- `robots.txt` запрещает ботов, которые собирают тексты и картинки для нейросетей. В шапке стоят `noai, noimageai` и `copyright`. В подвале — «Все права защищены, копирование материалов запрещено».
- Ограничение: полностью защитить открытый сайт нельзя. Скриншот или инструменты разработчика, открытые через меню браузера, обойдут любую защиту. Для фото и видео надёжнее водяной знак на самих файлах.

## Локальный просмотр

Откройте `index.html` в браузере или запустите `python3 -m http.server` и зайдите на http://localhost:8000.

## Публикация

**Сейчас:** сайт — https://mustmoviemedia.github.io/website/, репозиторий — https://github.com/mustmoviemedia/website (публичный). Бот обновляется из этого же репозитория через Cloudflare.

**GitHub Pages:** Settings → Pages → Source: *Deploy from a branch* → ветка `main`, папка `/ (root)` → Save. Сайт появится по адресу `https://<аккаунт>.github.io/<репозиторий>/`.

**Netlify:** Add new site → Import from GitHub → выбрать репозиторий. Build command — пусто, Publish directory — `/`.

**Свой домен:**
- GitHub Pages: Settings → Pages → Custom domain. У регистратора домена: для `www` — CNAME на `<аккаунт>.github.io`; для корня — A-записи `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`. Включите *Enforce HTTPS*.
- Netlify: Domain management → Add domain, затем DNS-записи, которые покажет Netlify (или перенесите DNS на Netlify). HTTPS выдаётся автоматически.
