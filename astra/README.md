# ASTRA Station 3D — ASTRAHUB

Интерактивная 3D-модель двух космических кофеен ASTRA Station:

- **STATION 01 · TASHKENT** — первый этаж здания в центре Ташкента, через дорогу Tashkent City Park. Фасад — горизонтальный модуль МКС (композитные панели, иллюминаторы, кольца жёсткости, вход-шлюз, вывеска ASTRA STATION, ночью светится как капсула). Внутри прямой зал 7 × 10 м, ~25 мест: Bar, Mini Kitchen, Space & Merch, Tour Desk, Crew Wall, иллюминаторы-экраны с видом на Землю. За дверью между баром и тур-деском — коридор и два санузла (WC 01 доступный для маломобильных гостей, WC 02).
- **STATION 02 · ASTRO CITY** — плато Устюрт (Каракалпакстан), обрыв чинка, закат и звёздное небо с Млечным Путём. Геодезический купол Ø 11,3 м (~100 м², ~35 мест), шлюз-коридор 12 м, Island Bar в центре, Space & Merch, Tour Desk, терраса с телескопом, солнечное поле, антенна, указатели и ворота ASTRO CITY, ASTRA Rover у входа. Санузлы — в сервисном модуле сбоку от шлюза: вестибюль с двумя раковинами и два WC.

Инженерия показана в обеих станциях: раковины и смесители (бар, кухня, санузлы), холодильники (кухонный, барные со стеклянными дверями, витрина десертов, холодильник с напитками в куполе), вентиляция (потолочные диффузоры, вытяжки в санузлах и над плитой, приточные решётки на торцах модуля, сопла в куполе, наружные блоки и воздуховоды), таблички EXIT, огнетушители, часы миссии с реальным временем (UTC+5 и UTC).

Детализация: мягкие тени в углах и под мебелью (ambient occlusion, N8AO), люди с суставами, одеждой разных цветов, обувью и причёсками, фасады Ташкента с настоящими окнами (откосы, рамы, подоконники, ночью часть окон горит), витрины первого этажа с интерьерами и вывесками, машины с нормальным кузовом, крупные панели стен внутри, колея на дороге Устюрта и светящиеся столбики у подъезда.

Стек: Vite + Three.js + postprocessing (bloom, тонмаппинг AgX, виньетка, сглаживание). Вся геометрия и текстуры процедурные, платных ассетов нет. Масштаб: 1 юнит = 1 м, силуэты людей ~1,6–1,85 м.

## Запуск

```bash
cd astra
npm install
npm run dev      # http://localhost:5173
npm run build    # готовый сайт в astra/dist
npm run preview  # проверить сборку локально
```

`dist/` — статические файлы с относительными путями (`base: './'`), их можно положить в любую папку хостинга (например, GitHub Pages: `…/website/astra/dist/`).

## Возможности

| Функция | Как работает |
|---|---|
| Меню станций | Стартовый экран и переключатель **Tashkent / ASTRO CITY** вверху |
| Orbit | Вращение вокруг станции (мышь/палец), колесо/щипок — масштаб. Повторное нажатие Orbit — сброс вида |
| Walk | Прогулка от первого лица: WASD + мышь (клик по сцене захватывает мышь, Esc — отпустить), Shift — быстрее. На телефоне — джойстик слева и свайп для обзора. Стены и мебель не проходятся, автоматические двери открываются при подходе |
| Day / Night | Плавная смена за ~1,6 с: солнце → луна, небо, подсветка LED, окна домов, фонари. На Устюрте «день» — это закат |
| Hotspots | Метки зон: название на английском + 1–2 строки по-русски, кнопка **Go** переносит к зоне |
| Tour | Облёт: фасад → вход → бар → мерч → тур-деск → зал (на ASTRO CITY в конце — терраса). Любое касание сцены останавливает тур |
| Cutaway | Режим разреза: снимает верхние этажи / оболочку купола, чтобы увидеть план сверху |
| 4K | Скриншот 3840 × 2160 PNG (если GPU не тянет 4K — максимум, который поддерживает устройство) |
| GLB | Экспорт модели станции в `.glb` (glTF 2.0, инстансинг деревьев/панелей, эмиссия LED) |
| Мини-план | В углу: зоны, мебель, позиция и направление камеры. Клик по плану — перейти туда пешком |

Горячие клавиши: `V` Orbit/Walk · `N` Day/Night · `T` Tour · `C` Cutaway · `M` план · `F` счётчик FPS · `Esc` остановить тур.

Отключить затенение в углах (если на слабом телефоне не хватает FPS): `?ao=0`. Ссылки сразу на нужный вид: `?station=astrocity`, `?station=tashkent&night=1`, `&mode=walk`, `&fps=1` (счётчик FPS), `&q=low|mid|high` (принудительное качество).

## Производительность на телефоне

- Уровни качества определяются автоматически (`high` — компьютер, `mid`/`low` — телефоны; iPad распознаётся как планшет, хотя Safari называет себя «Macintosh»): плотность пикселей, размер карты теней, MSAA или SMAA, разрешение bloom, плотность листвы и камней.
- Адаптивное разрешение: если FPS держится ниже 50, плотность пикселей снижается ступенями; когда запас появляется — возвращается.
- Тени статичные: карта теней пересчитывается только при смене дня/ночи и разреза, а не каждый кадр.
- Статическая геометрия склеивается по материалам: ~90–140 вызовов отрисовки и ~120–230 тыс. треугольников на кадр.
- Деревья, стойки купола, солнечные панели и камни — инстансы.

```
    │   ├── people.js      — силуэты людей
    │   ├── controls.js    — орбита, прогулка, джойстик, столкновения
    │   ├── hotspots.js    — метки зон
    │   ├── tour.js        — облёт по ключевым кадрам
    │   └── exporters.js   — скриншот 4K и GLB
    ├── scenes/
    │   ├── props.js       — мебель, кофемашины, витрина, экраны с Землёй
    │   ├── common.js      — свет, небо, туман, день/ночь для обеих станций
    │   ├── tashkent.js    — STATION 01
    │   └── astrocity.js   — STATION 02
    └── ui/ui.js, minimap.js
```

## Что поменять перед публикацией

- **Имена Founding Crew** на Crew Wall — сейчас это заглушки. Список в `src/config.js` → `FOUNDING_CREW` (20 имён, 4 колонки).
- Тексты зон и описания станций — там же, `ZONES` и `STATIONS`.
- Меню на экранах (MARS / LUNA / EARTH) — `menuTexture()` в `src/scenes/props.js`; расписание туров — тексты экранов в `tashkent.js` и `astrocity.js`.

## Лицензии и ассеты

- Шрифты Manrope и IBM Plex Mono — SIL Open Font License, подключены через `@fontsource`.
- Небо, окружение (IBL), текстуры, рельеф, деревья, мебель и люди сгенерированы кодом. HDRI-карты не используются: процедурное небо даёт одинаковое освещение днём и ночью и ничего не весит.
