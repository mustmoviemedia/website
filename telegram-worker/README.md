# Worker «mmm-brief»: бриф, чат на сайте и бот для менеджеров

Один Cloudflare Worker и один бот `@mmm_brief_bot`:

- **Бриф** с сайта уходит сообщением в группу «ЗАЯВКИ». Логика та же, что раньше.
- **Чат на сайте.** «Позвать менеджера» создаёт в группе отдельную тему на клиента: «Сайт · Имя · дата». Менеджер пишет в теме, и ответ появляется у клиента в окне чата.
- **Личные сообщения боту.** `/start` открывает частые вопросы. Менеджер подключается так же, через тему «Telegram · Имя · дата».
- **Хранилище.** Диалоги лежат в Durable Object `ChatHub` на SQLite. Токен и id группы живут только в секретах Cloudflare. В коде и на сайте их нет.

Почему один Worker, а не новый `mmm-chat`: у бота может быть только один вебхук, а секреты `BOT_TOKEN` и `CHAT_ID` уже заведены в `mmm-brief`. Адрес брифа при этом не меняется.

## Запуск (один раз, ~10 минут)

Нужен Node.js 18+ и доступ к аккаунту Cloudflare, где уже есть Worker `mmm-brief`.

```bash
cd telegram-worker
npx wrangler@4 login          # откроется браузер, войти в Cloudflare
npx wrangler@4 deploy         # зальёт новый код поверх mmm-brief и создаст хранилище ChatHub
npx wrangler@4 secret put WEBHOOK_SECRET   # вставить любую длинную случайную строку*
```

\* Строку можно получить так: `openssl rand -hex 32`. Сохраните её, она понадобится ниже.
Секреты `BOT_TOKEN` и `CHAT_ID` уже есть в Cloudflare, заново их вводить не нужно.

Затем подключите вебхук. Откройте в браузере:

```
https://mmm-brief.spotifyibrawkee.workers.dev/setup?key=<WEBHOOK_SECRET>
```

Ответ должен быть таким: `"webhook":{"ok":true}` и `"group":"ok"`. Worker сам вызывает `setWebhook` с `secret_token`, поэтому токен бота нигде вводить не нужно.

## Настройки в Telegram

1. **Включить темы.** Группа «ЗАЯВКИ» → Изменить → «Темы» (Topics) → включить.
2. **Сделать бота администратором.** Группа → Администраторы → Добавить `@mmm_brief_bot`. Нужно право «Управление темами». Администратор видит все сообщения группы; без этого бот не получит ответы менеджеров в темах.
3. **Имена менеджеров.** Каждый менеджер пишет боту `@userinfobot` и получает свой числовой id. Id впишите в `wrangler.toml`:
   ```toml
   MANAGERS = '{"123456789": "Георгис", "987654321": "Владимир"}'
   ```
   Затем снова выполните `npx wrangler@4 deploy`. Можно и без деплоя: Cloudflare → Worker → Settings → Variables. Если id не указан, клиент видит имя из профиля Telegram.

Если темы не включены или у бота нет прав, работает запасная схема. Уведомление приходит в общий чат, и менеджер **отвечает реплаем** на него или на любое сообщение клиента.

## Как работают менеджеры

- **Новый диалог.** В группе появляется «🔴 Новый диалог · имя · контакт · язык». В нём расчёт калькулятора, дата и последние сообщения клиента.
- **Кнопки под уведомлением:**
  - «✋ Беру» — все видят, кто взял диалог.
  - «👋 Приветствие», «📋 Уточнить детали», «💰 Отправить расчёт», «📅 Предложить созвон» — готовые тексты. Уходят клиенту на его языке (RU / UZ / EN).
  - «✅ Закрыть диалог».
- **Ответ клиенту.** Любой текст в теме уходит клиенту с подписью «Имя — MUST MOVIE MEDIA». Бот ставит 👍, когда сообщение доставлено.
- **Команды в теме:**
  - `/templates` — список шаблонов;
  - `/t greet` (или другой код) — отправить шаблон клиенту;
  - `/close` — закрыть диалог.
- **Шаблоны** лежат в `templates.js`. Подстановки: `{клиент}`, `{менеджер}`, `{расчёт}`, `{бриф}`.
- **Ответы помощника** на сайте и в боте берутся из `../knowledge.js`. Как добавить вопрос, написано в начале этого файла.
- **Рабочее время** — 10:00–20:00 по Ташкенту, настраивается в `HOURS` в `knowledge.js`. В другое время клиент видит: «Сейчас мы не на связи — ответим утром».

## Защита

- **Вебхук** принимается только с заголовком `X-Telegram-Bot-Api-Secret-Token`, равным `WEBHOOK_SECRET`. Команды и ответы менеджеров принимаются только из группы `CHAT_ID`. Другие группы бот игнорирует.
- **Чат и бриф** принимают запросы только с адреса сайта (`ALLOWED_ORIGINS` в `worker.js`, `EXTRA_ORIGINS` в `wrangler.toml`). Если подключите свой домен, допишите его туда.
- **Антиспам:**
  - скрытое поле-ловушка;
  - лимиты: 6 вызовов менеджера с одного IP в час, 20 сообщений за 5 минут, сообщение не длиннее 600 символов;
  - в брифе — проверка времени заполнения.
- **Телефон студии** нигде не показывается. Клиенту отвечают в чате или в Telegram.

## Проверка на своём компьютере

```bash
cd telegram-worker
printf 'BOT_TOKEN=test\nCHAT_ID=-100123\nWEBHOOK_SECRET=test\n' > .dev.vars   # файл не коммитится
npx wrangler@4 dev --var TG_API:http://127.0.0.1:8790 --var EXTRA_ORIGINS:http://127.0.0.1:8765
```

`TG_API` направляет запросы к Telegram на локальную заглушку, поэтому в настоящую группу ничего не уходит. Сайт на `http://127.0.0.1:8765` подключается к локальному воркеру строкой `window.MMM_CHAT_API = 'http://127.0.0.1:8787'` перед `chat.js`.

## Пока Worker не обновлён

Бриф работает, как раньше. Чат на сайте отвечает из базы знаний, а «Позвать менеджера» предлагает написать в Telegram или Direct.

## Автодеплой

Worker связан с GitHub (Cloudflare Workers Builds): каждый пуш в `main` сам собирает и выкладывает бота (`npx wrangler deploy` из папки `telegram-worker`). Вручную деплоить не нужно.
